# SAE_202-5
Dans le cadre de cette SAÉ, nous avons été amenés à concevoir un site web dédié au domaine du ski. L’objectif principal était de créer une plateforme moderne et fonctionnelle permettant aux utilisateurs de découvrir différents modèles de skis, d’obtenir des informations techniques, et d’effectuer des recherches ou réservations.

Pour cela, nous avons utilisé plusieurs technologies complémentaires :

HTML (HyperText Markup Language), pour structurer les différentes pages du site et organiser les contenus (textes, images, formulaires, menus).

CSS (Cascading Style Sheets), pour mettre en forme et styliser les pages, afin de proposer une interface attractive, ergonomique et adaptée à différents supports (ordinateurs, tablettes, smartphones).

SQL (Structured Query Language), afin de gérer la base de données du site, permettant de stocker et manipuler efficacement les informations relatives aux skis, aux utilisateurs ou encore aux réservations.

Ce projet nous a permis de mettre en pratique des compétences techniques en développement web, en gestion de données, mais aussi en conception d’une interface pensée pour l’expérience utilisateur. Le site de skis représente ainsi une application concrète reliant les aspects front-end et back-end du développement web.
